# Portfólio Web - Pedro Jorge

Portfólio responsivo em HTML, CSS, JavaScript e PHP opcional para apresentar perfil profissional, projetos, formação, stack e contato.

## Conteúdo principal

- Hero com proposta profissional, currículo em PDF e Instagram.
- Seção sobre com base no currículo.
- Projetos descritos por problema, solução e tecnologias.
- Formação em ADS, UX/UI Google/Coursera e experiência acadêmica como Product Owner.
- Formulário com validação no PHP.

## Como abrir

Abra `index.html` no navegador. Essa versão não depende de PHP e já inclui validação do formulário em JavaScript.

## Como rodar com PHP

Com PHP instalado:

```bash
php -S localhost:8000
```

Depois acesse:

```text
http://localhost:8000
```

## Personalização

- Edite o conteúdo em `index.html` ou, se preferir usar a versão dinâmica, ajuste os dados no topo de `index.php`.
- Atualize as imagens em `assets/` quando tiver prints reais dos projetos.
- O currículo usado pelo botão de download está em `assets/curriculo-pedro-jorge.pdf`.
